Native randomize default is True for this cylinder constructor. TD-MPC2 adapter ignores extra reset kwargs (including explicit randomize) and forwards only seed; TensorWrapper.reset does not accept a seed. With default True, this does not establish a mismatch for the actual training configuration, but the adapter cannot express arbitrary common reset contracts by itself. The independent evaluator uses the same NominalEnv for BOTH policies and thus avoids relying on that training reset interface. Evidence: test_nominal_audit reset probe and [src/fluidgym_rl/tdmpc2_adapter.py:44–46](/Users/jihyekim/Desktop/Fluidgym-RL/src/fluidgym_rl/tdmpc2_adapter.py:44).

Actuator last_control resets when the native domain is initialized (cylinder_env_base.py lines~360), then evolves within each episode. Missing actuator state from observations is a shared partial-observation property, not evidence of an adapter-specific bug. Same seeds need not produce identical training episodes because each runner consumes RNG differently. Evaluation contexts have matching dataset hashes; hashing establishes identical input files, not deterministic trajectories for arbitrary kernels.
